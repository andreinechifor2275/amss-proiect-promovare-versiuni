# Promovarea versiunilor între medii

Proiect AMSS 2026/2027.

## Tema
O echipă de dezvoltare vrea să țină evidența versiunilor unei aplicații
și a drumului lor prin medii: dev → staging → producție. O versiune
ajunge în producție doar după ce a trecut prin staging și a fost aprobată;
dacă apare o problemă, se poate reveni la versiunea anterioară (rollback).

## În afara proiectului
Nu modelăm build-ul efectiv, infrastructura, autentificarea
sau instrumente CI/CD reale.
